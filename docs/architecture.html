Factory Inventory Management System

A full-stack demo application for tracking inventory, orders, demand, and spending across multiple warehouses — built with a Vue 3 SPA, a FastAPI service layer, and an in-memory mock data store.

Global Filter System

Time Period

Months (Jan–Dec 2025) or quarters (Q1–Q4). Inventory has no time dimension.

Warehouse

San Francisco · London · Tokyo

Category

Circuit Boards · Sensors · Actuators · Controllers · Power Supplies
A fourth filter — Order Status (Delivered · Shipped · Processing · Backordered) — applies to order and dashboard data. Filter state lives in a single shared useFilters composable and flows to every view through URL query params.
